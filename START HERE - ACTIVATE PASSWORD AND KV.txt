ACTIVATE PASSWORD + KV SYNC ON YOUR EXISTING PORTAL

Do this only when your ordinary local threaded Portal is already working and you feel ready for the next step.

1. Open your live Portal and export every important thread.
2. Keep the SAME Netlify site. A different site address cannot see the IndexedDB data saved under the original address.
3. Complete the Cloudflare Worker, KV namespace, binding and secret steps in `KV-Cloudflare-Workers-sync-guide.html`.
4. Add every required Netlify environment variable from that guide.
5. Add your companion name and prompt to this activation folder's `index.html`, just as you did for the first Portal.
6. Deploy THIS `Password + KV Sync - Activate Later` folder over the same Netlify site.
7. Unlock the Portal with the password you configured.
8. Confirm the existing local threads appear, then use Storage & sync to complete the first cloud sync.

Do not upload this activation folder before the Cloudflare and Netlify configuration is complete. Its secure proxy deliberately refuses model requests when authentication is not configured.

Never paste a password, hash, API key, Worker token or session secret into index.html or any public file.
